## Узгодженість із попередніми завданнями

Відповідність сценаріїв перевіряється за `lab2/gherkin.md`. У діаграмах використовуються сутності попередньої ER-моделі: `User`, `Room`, `Booking`, `BookingStatus`. `BookingService`, `BookingRepository` та інтерфейс — компоненти взаємодії, а не окремі сутності ER-моделі.

Діаграми містять виклики, повернення результатів, activation bars і альтернативні фрагменти `alt`. Операції блокування та транзакції показують запропонований технічний спосіб забезпечити атомарну перевірку, а не готову реалізацію програми.

## Перегляд і генерація PNG

Відкрити будь-який файл з папки `model/` у PlantUML (наприклад, через розширення PlantUML для VS Code) та експортувати у PNG. Після змін `.puml` відповідний файл у `renders/` потрібно оновити.
