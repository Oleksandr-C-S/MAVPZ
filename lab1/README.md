# Lab 1 — ER Model

## Домен

Для першої лабораторної роботи я обрав систему бронювання навчальних аудиторій університету.

Система повинна зберігати інформацію про користувачів, корпуси, аудиторії, бронювання та обладнання.

Користувач може створити бронювання певної аудиторії на визначений проміжок часу.

Кожна аудиторія знаходиться в одному корпусі.

Аудиторії можуть мати різне обладнання, наприклад проектори, комп'ютери або інтерактивні дошки.

Один тип обладнання може використовуватися в декількох аудиторіях, тому між аудиторіями та обладнанням виникає зв'язок багато-до-багатьох.

Для цього зв'язку буде використана окрема сутність `RoomEquipment`, у якій також можна зберігати кількість обладнання.

## Основні сутності

- User
- Building
- Room
- Booking
- Equipment
- RoomEquipment

## Мета моделі

Побудувати логічну ER-модель предметної області та визначити:

- сутності;
- атрибути;
- первинні ключі;
- зовнішні ключі;
- зв'язки;
- кардинальності.

SQL-схема та ORM у цій лабораторній роботі не створюються.
